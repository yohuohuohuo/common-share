## 调整而不是删减

原22项主任务完整覆盖为23个阶段内任务：只有T19被拆为P02.03（启动/单实例/任务/调度骨架）和P07.01（全部handler接线/恢复验收）。其他原任务一对一归属，不按链复制客户端或执行器。

U01—U06分别并入各阶段的类型、迁移、生产、展示与验收，不再有第九份必须跨查的专项执行清单。SSE/D01仍后续增强。产品是完整交易应用，中间阶段不等于V0.1交付完成。

## Agent使用方式

产品目录已经由用户确定且已获实施授权后，给当前Agent的指令可保持为：

```text
执行总览指定的当前P阶段，先读execution-rules、当前阶段计划和前一阶段handoff。
只执行当前阶段及其内联增补；不重新研究全部参考项目，不实施下一阶段。
核对当前代码接口与前置验收，先写失败测试再实现，实际验证后提交。
更新execution-status与docs/execution/Pxx-handoff.md，报告外部NOT_RUN/BLOCKED。
不得启用真实交易或向生产GMGN提交测试订单。
```

P01前没有前序handoff；从已确认的新产品目录建立工程。P08只读验证可复用P02—P04早期probe；实盘始终需要独立运行授权。资料仓库不是产品目录。
